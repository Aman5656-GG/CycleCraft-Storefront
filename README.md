# CycleCraft – Bicycle Builder & Accessories Storefront

## Live Demo
https://cyclecraft-storefront.vercel.app

## About the Project
CycleCraft is a responsive bicycle customization and commuter cycling accessories storefront. It allows users to customize bicycle components, calculate prices, explore cycling accessories, and manage their shopping cart.

## Features
- Interactive Bicycle Builder
- Custom bicycle component selection
- Automatic bicycle price calculation
- Bicycle build summary
- Cycling accessories storefront
- Product search functionality
- Price sorting (Low to High and High to Low)
- Add to Cart functionality
- Shopping cart with quantity controls
- Remove products from cart
- Cart data persistence using Local Storage
- Responsive user interface

## How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/Aman5656-GG/CycleCraft-Storefront.git
```

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server.
